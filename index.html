Can change after the swap

The replacement accepts the same request and answers differently. Nothing errors, so nothing alerts you. These are the things we measure:

Output format
Markdown where your UI expects plain text, or the reverse.
Length
Longer or shorter answers move your layout and your token bill.
Tone
A support reply that sounded like your company may stop sounding like it.
Refusals
Requests the old model handled may be declined, or the other way round.
JSON shape
A missing key, a renamed field or prose around the JSON breaks the parser downstream.
Latency
Response time can move enough to trip timeouts in webhooks and workflow steps.
Cost
Per-token prices and output length together set the new monthly bill.

Fine-tuned on a retiring base?

OpenAI’s fine-tuning guide says fine-tuned models “will remain available for inference until their base models are deprecated.” The same guide lists no GPT-5 or GPT-5.6 model for fine-tuning, and says OpenAI “is winding down the fine-tuning platform.” So you may not be able to simply retrain on the replacement. The behaviour has to be rebuilt with structured prompting, few-shot examples and output schemas, then measured against your held-out data.

Questions

Frequently asked

Is plain gpt-4o affected on 23 Oct?

No. Only the dated snapshot gpt-4o-2024-05-13 is on the 23 Oct list. Plain gpt-4o, gpt-4o-mini, gpt-4.1 and gpt-4.1-mini are not on it. gpt-4.1-nano is. Source: OpenAI deprecations page, read 9 Oct 2026.

Does the checker send my code anywhere?

No. It is plain JavaScript in checker.js, running in your tab. It contains no network code, and the page’s Content-Security-Policy (connect-src 'none') blocks scripts from making connections. You can disconnect from the internet after the page loads and it still works.

Why not just change the model name myself?

You can, and for some projects that is enough. The list and the checker on this page are free. What a rename does not tell you is whether the new model still returns the format, length, tone and JSON your code expects. If you have time to run your own before/after comparison, do. If you don’t, that comparison is what we sell.

Do you guarantee the new model behaves the same?

No. Nobody can promise identical output from a different model. We promise a measured comparison on your own inputs and a pull request. We do not guarantee output parity, quality, uptime, revenue or compliance.

What access do you need?

Enough to open a pull request in your repository (or a workflow export you import yourself), plus a staging API key that you create for the job and revoke afterwards. We do not take production access or passwords.

We fine-tuned a model on a retiring base. Can’t we just retrain on the replacement?

Maybe not. OpenAI’s fine-tuning guide lists no GPT-5 or GPT-5.6 model for fine-tuning and says the fine-tuning platform is being wound down (read 9 Oct 2026). The Fine-tune Replacement offer rebuilds the behaviour with structured prompting, few-shot examples and output schemas, then compares it on held-out data from your own training set.
